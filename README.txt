FREE DEPLOYMENT OPTION — GITHUB PAGES
1. Create a PUBLIC GitHub repository named "watchx-download".
2. Upload the included index.html to the root of the repository.
3. In repository Settings > Pages, choose Deploy from a branch > main > / (root), then Save.
4. After GitHub Pages reports the site is live, its URL will typically be:
   https://YOUR_USERNAME.github.io/watchx-download/
5. Open that link in Android and iPhone browsers to confirm redirection.
6. Create a QR code containing that exact live URL, NOT either store URL.

Alternatively upload index.html as your website's /watchx/ landing page.

NOTE: The webpage is ready, but the QR code cannot redirect devices until it is hosted at a public HTTPS URL. GitHub Pages requires your own account and publication action. When you have the live URL, provide it to ChatGPT to generate a printable QR code.
